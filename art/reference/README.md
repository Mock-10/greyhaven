# Reference material from the user

## palettes/
- `gray-weather-8x.png` and `gray-weather-palette-example-…png`: **the chosen palette (Grey Weather).** The game uses it lifted slightly (less dark and less pale), with gold added for valuables and interactables. The exact ramps the game uses are in `art/palette.json` and `art/source/sdf.py` (`RAMP_HEX`). Those files win over these images.
- `user_palette_strip.png`: the colour strip the user shared alongside it.
- `not_chosen/`: other palettes the user considered (Cretaceous-16, Ephemera, Waldgeist). **Don't use them.** They're kept only as a record.

## Related drafts (in `art/drafts/`)
- `closeups/closeup_store_day.png`, `closeup_store_dusk.png`: zoomed street views of the approved art style (store, cars, cop, prompts, gold rims).
- `interiors/interiors_overview.png`: all four interior drafts on one sheet.

Early test renders (voxel figures and rounded cars) were rejected by the user and are deliberately **not** included.
